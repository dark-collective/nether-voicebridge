# Architecture Decision Records

One file per decision, numbered, written while the reasoning is fresh. An accepted ADR is not edited;
a later decision that changes it gets its own ADR and marks the old one *superseded*.

Each record has: **Context** (the problem and the constraints), **Decision** (what we do), **Alternatives**
(what we considered and why it lost), **Consequences** (what gets easier, what gets harder, follow-ups).
